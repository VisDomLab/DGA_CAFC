01 / ABSTRACT

Build robust representations beyond source domains.

Source-free domain adaptation (SFDA) adapts a source-trained model to unlabeled target domains without access to the source data. Two important failure modes remain: attention drift, where learned attention shifts toward spurious or background cues under distribution shift, and domain-gap-agnostic initialization, where the same source model is used irrespective of the target-domain shift.

We propose DGA-CAFC, which combines Counterfactual Attention-based Feature Consistency (CAFC) and Domain-Gap Aware Source Model Selection (DGASS). CAFC stabilizes attention-conditioned features using counterfactual-inspired normalized attention perturbations, while DGASS uses prediction entropy on unlabeled target data to select an appropriate source-model variant before adaptation.

CAFC is also applicable as a lightweight regularizer for domain generalization (DG), where target-domain data are entirely unavailable during training.

02 / FRAMEWORK

Two modules. One robust framework.

DGASS selects the initialization before adaptation; CAFC regularizes learned features throughout training.

03 / METHODOLOGY

Make attention stable. Make initialization adaptive.

MODULE / 01
◎

CAFC

Counterfactual Attention-based Feature Consistency

Builds uniform, random, and reversed normalized attention maps. Aligning features computed from learned and counterfactual attention encourages robustness to attention drift.

Feature stability · SFDA + DG
MODULE / 02
◇

DGASS

Domain-Gap Aware Source Model Selection

Measures uncertainty via target prediction entropy and selects between complementary source-model variants, providing an initialization suited to the estimated domain-gap severity.
